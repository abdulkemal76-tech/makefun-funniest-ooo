A program that writes a single line of an out-of-office auto-reply, the
funniest one line it can, in 140 characters or fewer, to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```

It writes exactly one line of text, no image, no link, no second line.
